# TrayDrop 0.1.1

A Windows preview update focused on reliable tray-panel reopening and easier per-user setup.

## What's changed

- Recover a disposed drop panel instead of raising an error when reopening TrayDrop.
- Use a live panel for tray clicks, second-launch activation, connection/save-location dialogs, pairing notifications, and upload notifications.
- Preserve the running server, paired-device authorization, shared files, and receive location when recreating the panel.
- Include an optional setup script with Start menu and desktop shortcuts that explicitly show the panel.
- Support quiet startup with Windows when setup is run with `-StartWithWindows`.
- Refresh installation, usage, troubleshooting, architecture, and release documentation.

## Download and open

1. Download **TrayDrop-0.1.1-win-x64.zip** and **SHA256SUMS.txt**.
2. Verify the archive checksum, extract the complete ZIP, and open its **TrayDrop** folder.
3. For portable use, run **TrayDrop.exe** as a normal user and click its icon in the notification area.
4. For shortcuts and optional Windows startup, open PowerShell in that folder and run `.\Install-TrayDrop.ps1 -StartWithWindows`.
5. Open **Start > TrayDrop**, choose **Connect a device**, and scan the QR code from a phone on the same trusted Wi-Fi.

The Windows x64 executable is self-contained and does not require a separate .NET installation. The setup script also works without the SDK or source checkout. The ZIP includes the usage guide, MIT project license, and original dependency licenses/notices.

```powershell
Get-FileHash -LiteralPath .\TrayDrop-0.1.1-win-x64.zip -Algorithm SHA256
```

See the [usage guide](https://github.com/istartedcoding/TrayDrop/blob/v0.1.1/docs/HOW_TO_USE.md) for downloaded-script restrictions, manual startup, and network requirements.

## Existing installations

This release does not update an installed or running copy automatically. Downloading it does not change your current setup.

To update when you choose, finish transfers, choose **Exit** from the existing tray menu, extract this release into a separate folder, and run its setup script. Existing settings and completed received files are preserved. Restarting resets phone pairing and outgoing links, so scan the new QR code afterward.

The setup script refuses to replace a running app. It does not stop transfers, launch the app, require administrator privileges, or change network/firewall settings.

## Verification

- **54 passing regression cases**, including **10 native Windows interaction cases**.
- Coverage includes native file drag/drop, hidden/disposed-panel recovery, activation, dialogs, pairing/upload notifications, retained authorization/shares, settings, and byte-exact two-way HTTP transfers.
- The release package excludes debugging symbols and includes SHA-256 values for the archive and extracted executable.
- Release preparation uses a separate versioned output and does not reinstall or restart an existing local app.

The packaged executable was not launched in the existing app's Windows session. This release is not a physical-phone compatibility certification, throughput benchmark, or security certification.

## Security and limitations

**HTTP traffic is unencrypted. Use trusted local networks only.** Allow TrayDrop through Windows Firewall on **Private networks only**. Do not expose its port to the internet, enable router port forwarding, or share live pairing invitations.

This is an unsigned pre-release. Verify the release origin and checksum; do not disable system security broadly.

Windows x64 and individual files only. There are no native mobile apps, folder transfers, upload resumption, encrypted transport, MSI/MSIX installer, signed binaries, or automatic updates. Browser devices appear after pairing, not through automatic network-wide discovery.
